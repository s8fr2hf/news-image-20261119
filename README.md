A program that copies a pre-rendered front-page poster summing up the world news of Thursday 19 November 2026 — the Shenzhen trilateral summit, the ICJ genocide ruling, the Crimea bridge, the Gulf and Gaza — to /output/entry.png. The poster is drawn by render.py (Pillow, build-time only); main.py itself uses only the Python standard library.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```
